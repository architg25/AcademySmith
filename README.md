
# AcademySmith

## Academy Smith Game Mod

Welcome to AcademySmith! This is a game mod specifically designed for Academy Smith, aimed at enhancing the gaming experience and providing more creative possibilities.

## Installation Instructions

To install this mod, please follow these steps:

1. Download the latest [AcademySmith.zip](https://raw.githubusercontent.com/XRMT01/AcademySmith/main/version/0.0.9/Academy%20Smith-0.0.9.dll).
2. Extract the folder.
3. Copy the extracted folder to the Academy Smith game's mod folder.
   - For Windows users: `C:\Users\<username>\AppData\Roaming\Academy Smith\Mods`
4. Launch Academy Smith and enjoy the new mod!
